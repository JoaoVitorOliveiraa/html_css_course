O Novo Elemento HTML <selectedcontent> Vai Mudar Seus Selects

A ideia é simples: vincular um seletor a uma área que mostra o conteúdo da opção escolhida. Em vez de exibir apenas texto simples, você pode renderizar HTML rico dentro do próprio <select>.

1. O problema dos selects tradicionais

Até recentemente, os elementos <select> só conseguiam exibir texto simples como rótulo da opção selecionada. Qualquer tentativa de usar HTML dentro de um <option> era ignorada ou achatada em texto puro.

Select tradicional (sem <selectedcontent>)

Perceba que o texto precisa ser "achatado" em uma única linha. Não há como destacar visualmente o badge, o nome e a descrição.

2. A solução com <selectedcontent>

O elemento <selectedcontent> é colocado dentro de um <button> (que, por sua vez, fica dentro do <select>). Ele serve como um "slot" que espelha o conteúdo HTML da opção atualmente selecionada.

Select moderno (com <selectedcontent>)

Agora o select exibe o badge colorido, o nome em negrito e a descrição — tudo formatado com HTML e CSS reais.

3. Estrutura necessária

Para que o <selectedcontent> funcione, alguns requisitos precisam ser atendidos:

  1. O <select> deve ter appearance: base-select (via CSS) para habilitar o novo comportamento.
  2. O primeiro filho do <select> deve ser um <button> contendo o <selectedcontent>.
  3. As <option> podem conter HTML rico (spans, strong, etc.) que será espelhado pelo <selectedcontent>.
  4. O seletor ::picker(select) também recebe appearance: base-select para estilizar a lista suspensa. 
<select id="plan">
  <button>
    <selectedcontent></selectedcontent>
  </button>
  <option value="pro" selected>
    <span class="row">
      <span class="badge b2">P</span>
      <strong>Pro</strong>
      <span>• Projetos sérios</span>
    </span>
  </option>
</select>

4. Estilização

O <selectedcontent> pode ser estilizado como qualquer outro elemento. No exemplo abaixo, ele recebe um fundo escuro, borda e padding para se destacar dentro do select. 

select,
::picker(select) {
  appearance: base-select;
}

option {
  padding: 5px;
}

option::checkmark {
  display: none;
}

option:checked {
  background-color: #ffd166;
}

selectedcontent {
  display: grid;
  gap: 6px;
  background: #0a1433;
  border: 1px solid #22306a;
  border-radius: 12px;
  padding: 14px;
  min-height: 56px;
}

5. Suporte e considerações

  • Navegadores: atualmente suportado no Chrome 135+ e Edge 135+. O Firefox ainda não implementou.
  • Fallback: em navegadores sem suporte, o <selectedcontent> é ignorado e o select se comporta como o tradicional.
  • Acessibilidade: o conteúdo espelhado mantém a semântica original da opção selecionada.
  • Flexibilidade: como o conteúdo é HTML real, você pode usar imagens, ícones SVG, badges coloridos, etc.
