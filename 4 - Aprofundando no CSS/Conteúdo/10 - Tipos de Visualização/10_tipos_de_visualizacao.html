O que é a propriedade display?

A propriedade display define como um elemento HTML será exibido na página. Cada valor altera o comportamento do elemento em relação ao fluxo do documento, ao box model e à quebra de linhas.

Os valores mais comuns são: block, inline, inline-block e none.

1. display: block

O elemento ocupa toda a largura disponível e sempre quebra linha. O box model (largura, altura, padding, margin e border) se aplica completamente.

Repare que cada bloco fica em sua própria linha, mesmo que haja espaço ao lado.

2. display: inline

O elemento ocupa apenas o espaço do conteúdo e não quebra linha. O box model não se aplica verticalmente, e padding/margin só funcionam na horizontal.

Inline 1 Inline 2 Inline 3

Os elementos ficam lado a lado, mas altura e margin vertical são ignoradas.

3. display: inline-block

O melhor dos dois mundos: o elemento fica lado a lado com outros (como inline), mas o box model se aplica completamente (como block).

Botão 1 Botão 2 Botão 3

Cada botão tem altura, padding e margin aplicados, mas continuam lado a lado.

4. display: none

O elemento desaparece completamente da tela e do fluxo do documento — como se não existisse no HTML.

Este texto contém uma palavra INVISÍVEL que foi escondida com display: none.

A palavra "INVISÍVEL" não aparece e não ocupa espaço algum.

inline-block Não Completo Do conteúdo
none — — Não renderiza

Dica: display: none vs visibility: hidden

display: none remove o elemento completamente do fluxo. Já visibility: hidden apenas o deixa invisível, mas ele continua ocupando espaço na página.
