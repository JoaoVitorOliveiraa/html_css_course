Unidades de Viewport Dinâmicas: dvh, lvh e svh

As unidades vh tradicionais sempre causaram problemas em dispositivos móveis por causa das barras de navegação que aparecem e desaparecem. As novas unidades dvh, lvh e svh resolvem isso de forma elegante.

1. O problema com vh

Em navegadores móveis, a barra de endereço e a barra de ferramentas aparecem e desaparecem conforme o usuário rola a página. Isso faz com que a altura real do viewport mude constantemente. O 100vh tradicional sempre usa o maior valor possível, o que pode causar overflow ou cortes no conteúdo.

Exemplo: height: 100vh

Em um celular, este elemento pode ultrapassar a área visível quando a barra de endereço está aberta, criando barras de rolagem indesejadas.

100vh

2. As três novas unidades

Cada uma representa um momento diferente do viewport móvel:

dvh

Dynamic viewport height — altura dinâmica. Muda em tempo real conforme as barras do navegador aparecem ou desaparecem.

100dvh

lvh

Large viewport height — altura máxima. Usa o viewport quando as barras do navegador estão ocultas (maior área possível).

100lvh

svh

Small viewport height — altura mínima. Usa o viewport quando as barras do navegador estão visíveis (menor área possível).

100svh

3. Comparação visual

Imagine um celular onde a barra de endereço ocupa 80px. Veja como cada unidade se comporta:

lvh

Maior
Barras ocultas

dvh

Dinâmico
Muda em tempo real

svh

Menor
Barras visíveis

Relação: svh ≤ dvh ≤ lvh. O dvh sempre fica entre os dois extremos e se ajusta conforme o usuário interage com a página.

4. Quando usar cada unidade

dvh
  • Hero sections que ocupam a tela toda
  • Modais e overlays em tela cheia
  • Quando você quer que o conteúdo se ajuste em tempo real sem cortes
lvh
  • Elementos que devem ocupar a maior área possível
  • Backgrounds fixos que não devem "pular"
  • Quando você quer garantir que o conteúdo caiba mesmo com barras ocultas
svh
  • Conteúdo que nunca deve ser cortado
  • Layouts críticos de acessibilidade
  • Quando você quer o pior cenário (barras visíveis) como referência

5. Exemplo de código

/* Hero que ocupa exatamente o viewport visível */
.hero {
  height: 100dvh;
}

/* Background que nunca "pula" ao rolar */
.background {
  min-height: 100lvh;
}

/* Container que nunca é cortado */
.container-seguro {
  max-height: 100svh;
  overflow-y: auto;
}

Todas as três unidades também existem na versão horizontal: dvw, lvw e svw. E há ainda as versões para os eixos menores/maiores: dvmin/dvmax, etc.

6. Suporte dos navegadores

  • Chrome/Edge: 108+
  • Firefox: 101+
  • Safari: 15.4+
  • Fallback: use 100vh antes da unidade nova. Navegadores antigos ignoram a linha que não entendem. 
.hero {
  height: 100vh;   /* fallback para navegadores antigos */
  height: 100dvh;  /* navegadores modernos usam esta */
}
