Background Color e Image

O que é a propriedade background?

A propriedade background é um atalho (shorthand) que agrupa várias propriedades relacionadas ao fundo de um elemento: background-color, background-image, background-position, background-size, background-repeat, entre outras.

Vamos ver cada uma delas separadamente, com exemplos práticos.

1. background-color

Define a cor de fundo do elemento. Aceita qualquer formato de cor: nome (red), hexadecimal (#f1f1f1), rgb(), hsl(), etc.

Este bloco tem background-color: #f1f1f1.

2. background-image

Define uma ou mais imagens de fundo para o elemento. Pode ser uma URL externa (url()) ou um gradiente (linear-gradient(), radial-gradient()).

Este bloco tem uma imagem de fundo via url().

Este bloco usa linear-gradient() como fundo.

3. background-position

Define a posição inicial da imagem de fundo. Aceita dois valores: um para o eixo X (horizontal) e um para o eixo Y (vertical). Pode ser em %, px ou palavras-chave (top, center, bottom, left, right).

4. background-size

Define o tamanho da imagem de fundo. Os valores mais comuns são:

  • auto — tamanho original da imagem (padrão).
  • contain — redimensiona para que a imagem inteira caiba no elemento, mantendo a proporção.
  • cover — redimensiona para cobrir todo o elemento, mesmo que parte da imagem seja cortada.
  • 100px 50px — largura e altura específicas.

5. background-repeat

Define se a imagem de fundo deve ser repetida e em quais eixos:

  • repeat — repete nos dois eixos (padrão).
  • no-repeat — não repete.
  • repeat-x — repete apenas na horizontal.
  • repeat-y — repete apenas na vertical.

7. Gradientes com direção

O linear-gradient() aceita um ângulo em graus para definir a direção:

  • 0deg — de baixo para cima
  • 90deg — da esquerda para a direita
  • 180deg — de cima para baixo

8. O atalho background

Todas as propriedades acima podem ser escritas de uma vez usando o atalho background. A ordem recomendada é: 

background:
  [background-color]
  [background-image]
  [background-position] / [background-size]
  [background-repeat];

Exemplo:

background: #f1f1f1 url('imagem.jpg') center / cover no-repeat;

Resumo das propriedades

Propriedade O que faz Valores comuns
background-color Cor de fundo #f1f1f1, red, rgb()
background-image Imagem ou gradiente de fundo url(), linear-gradient()
background-position Posição da imagem center, 50% 0, top right
background-size Tamanho da imagem contain, cover, 100px 50px
background-repeat Repetição da imagem no-repeat, repeat-x, repeat-y
